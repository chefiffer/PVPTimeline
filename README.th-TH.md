# PvP Timeline

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [한국어](README.ko-KR.md) | [Русский](README.ru-RU.md) | [Português (Brasil)](README.pt-BR.md) | [Español](README.es-ES.md) | **ไทย** | [Tiếng Việt](README.vi-VN.md) | [日本語](README.ja-JP.md) | [Deutsch](README.de-DE.md) | [Français](README.fr-FR.md)

ไทม์ไลน์แอ็กชันส่วนตัวแบบเรียลไทม์สำหรับ PvP ใน FINAL FANTASY XIV

ดูการใช้แอ็กชัน การร่าย ระยะรอใช้ซ้ำร่วม (GCD) การล็อกแอนิเมชัน แอนิเมชันของตัวคุณเอง และผลตอบกลับของเอฟเฟกต์ได้บนไทม์ไลน์เดียว เพื่อทบทวนว่าใช้แอ็กชันเมื่อใด เอฟเฟกต์มาถึงเมื่อใด และแทรก ability ใดไว้ระหว่างนั้น

![ตัวอย่าง PvP Timeline ภายในเกม](assets/pvp-timeline-preview.gif)

> นี่เป็นรุ่นทดสอบ การอัปเดตเกมอาจกระทบการสังเกตและการแสดงผล และบางช่วงของแอ็กชันอาจยังไม่มีผลตอบกลับ ไทม์ไลน์แสดงสิ่งที่สังเกตได้ในเครื่อง ไม่ใช่การสร้างกระบวนการตัดสินการโจมตีภายในเซิร์ฟเวอร์ขึ้นใหม่อย่างแม่นยำ และไม่ทำให้การใช้แอ็กชันเป็นอัตโนมัติ

## หลักการทำงาน

![การสังเกตในเครื่องและการไหลของข้อความ](assets/how-pvp-timeline-works.png)

แผนภาพแยกข้อความที่แลกเปลี่ยนระหว่างไคลเอนต์เกมกับเซิร์ฟเวอร์ออกจากข้อมูลเวลาที่ปลั๊กอินสังเกตได้ในเครื่อง PvP Timeline บันทึกคำขอใช้แอ็กชันที่ได้รับการยอมรับ สถานะการร่ายและคูลดาวน์ที่มองเห็นในเครื่อง การล็อกแอนิเมชัน การเล่นแอนิเมชันของตัวเอง ข้อความเอฟเฟกต์ที่ได้รับ และภาพรวมสถานะปัจจุบัน สีของแต่ละแทร็กมีความหมายเดียวกับไทม์ไลน์เริ่มต้น

ปลั๊กอินไม่ส่งแพ็กเก็ตการต่อสู้เพิ่มเติมและไม่สามารถดูขั้นตอนการตัดสินใจภายในเซิร์ฟเวอร์ได้ การกดปุ่มจริงที่ไม่กลายเป็นคำขอแอ็กชันของเกมจะสังเกตไม่ได้ เวลาของผลตอบกลับคือเวลาที่ไคลเอนต์ในเครื่องได้รับข้อความ จึงรวมความหน่วงของเครือข่าย เซิร์ฟเวอร์ และไคลเอนต์

## ทำอะไรได้บ้าง

- **แยกเลนแอ็กชัน:** ไอคอนขนาดใหญ่ด้านล่างแสดง spell, weaponskill และแอ็กชันพิเศษบางชนิด ส่วนไอคอนเล็กด้านบนแสดง ability ไม่เกินสองแถว
- **แยกแทร็กเวลา:** GCD เวลาร่าย การล็อกแอนิเมชัน และการเล่นแอนิเมชันถูกบันทึกแยกจากกัน
- **ผลตอบกลับของเอฟเฟกต์:** รูปสี่เหลี่ยมข้าวหลามตัดสีชมพูระบุความเสียหาย การรักษา การใส่สถานะ หรือผลที่รองรับ ผล critical/direct hit จะเพิ่มแสงนุ่ม ๆ ให้ไอคอนต้นทาง
- **เอฟเฟกต์ล่าช้า:** การระเบิดอัตโนมัติและช่วงต่อเนื่องที่รองรับจะเชื่อมกับการใช้เดิม หรือแสดงเป็นไอคอนโปร่งแสงโดยไม่สร้างการกดปุ่มที่ไม่มีอยู่จริง
- **สถานะของตัวเอง:** ประวัติและเวลาสถานะแบบกะทัดรัด รวม buff ที่คัดเลือกและ debuff ที่สังเกตได้
- **ปรับแต่งรูปลักษณ์:** ล็อกให้คลิกทะลุ แนวนอน/แนวตั้ง เลื่อนย้อน สี ความทึบพื้นหลัง ขนาดไอคอน และสเกลโดยรวม
- **หยุดและทบทวน:** หยุดหน้าจอเพื่อดูแอ็กชันล่าสุด หรือล้างบันทึกเพื่อเริ่มทดสอบใหม่

การสังเกตจำกัดอยู่ในพื้นที่ที่รองรับของ **Wolves' Den Pier, Crystalline Conflict, Frontline และ Rival Wings** เท่านั้น และไม่เปิดใช้ในพื้นที่ PvE ทั่วไป แผนที่ใหม่ต้องได้รับการเพิ่มลงในรายการรองรับ

## เริ่มต้นใช้งาน

### การติดตั้ง

ต้องใช้สภาพแวดล้อมที่รองรับปลั๊กอิน **Dalamud API 15** โปรดใช้รุ่นที่เข้ากันได้กับเกมและ Dalamud ปัจจุบัน

1. ติดตั้งและเปิด XIVLauncher โดยเปิดใช้งาน Dalamud
2. เปิด **Dalamud Settings → Experimental**
3. เพิ่ม URL คลังปลั๊กอินแบบกำหนดเอง:

   ```text
   https://raw.githubusercontent.com/chefiffer/dalamud-plugins/main/repo.json
   ```

4. เปิด Plugin Installer ค้นหา **PVPTimeline** แล้วติดตั้ง
5. ใช้คำสั่งต่อไปนี้ในแชตเกมเพื่อเปิดการตั้งค่า:

   ```text
   /pvptimeline
   ```

6. เข้า Wolves' Den Pier หรือแผนที่ PvP ที่รองรับ แล้วใช้แอ็กชันเพื่อดูไทม์ไลน์

### การตั้งค่าครั้งแรก

เริ่มโดยปิด **Combat only** และทดสอบกับหุ่นฝึกใน Wolves' Den Pier:

1. ปลดล็อก overlay ในแท็บ **Display** แล้วเลื่อนและปรับขนาด
2. ในแท็บ **Layout** ปรับขนาดไอคอน GCD/ability ตำแหน่งและความหนาของแถบ
3. เมื่อจัดวางเสร็จ ให้เปิด **Locked** เพื่อให้คลิกทะลุและป้องกันการกดผิด

ไทม์ไลน์ที่ล็อกแล้วคลิกโดยตรงไม่ได้ ใช้ `/pvptimeline` เพื่อเปิดการตั้งค่าอีกครั้ง ขณะปลดล็อกสามารถคลิกขวาที่ไทม์ไลน์ได้ด้วย

## วิธีอ่านไทม์ไลน์

### ไอคอนแอ็กชันและเวลา

`0s` คือเวลาสังเกตปัจจุบัน ค่าติดลบคืออดีต ระหว่างแสดงผลสด เส้นตารางและตัวเลขจะอยู่กับที่ ขณะที่แอ็กชันและแถบเคลื่อนไปทางประวัติ

เลนล่างที่มีไอคอนใหญ่ไม่ได้หมายความว่าทุกแอ็กชันใช้ GCD เพราะ Limit Break และแอ็กชันพิเศษบางชนิดก็อยู่ในเลนนี้ แถบ GCD สีน้ำเงินจะวาดเฉพาะเมื่อสังเกตพบคูลดาวน์ร่วมจริง

| รูปลักษณ์เริ่มต้น | ความหมาย |
| --- | --- |
| แถบสีน้ำเงิน | GCD ที่สังเกตได้ |
| แถบสีเขียว | ช่วงร่ายที่สังเกตได้ในเครื่อง |
| แถบสีเหลืองสว่างสั้น | การล็อกแอนิเมชันที่บันทึกแยกจาก GCD |
| แถบสีม่วง | ช่วงเล่นแอนิเมชันของตัวเองที่สังเกตได้ |
| ข้าวหลามตัดสีชมพูทึบ | ผลโดยตรง เช่น ความเสียหาย การรักษา หรือสถานะ; สำหรับแอ็กชันเคลื่อนที่ที่ตรวจสอบแล้วบางชนิดอาจหมายถึงการตอบรับจากเซิร์ฟเวอร์ |
| ข้าวหลามตัดสีชมพูโปร่ง | ผลเช่นภาพเอฟเฟกต์หรือการเปลี่ยนเกจ; เพียงอย่างเดียวไม่ยืนยันความเสียหายหรือการรักษา |
| ไอคอนโปร่งแสง | การร่ายที่ยังไม่ยืนยัน หรือเอฟเฟกต์จริงที่ไม่มีบันทึกการกดด้วยตนเอง; ไม่ได้หมายความว่ากดอีกครั้ง |
| แสงรอบไอคอน | critical hit, direct hit หรือ critical direct hit จากข้อความเอฟเฟกต์จริง |
| แถบสีเทาบาง (ปิดโดยค่าเริ่มต้น) | คูลดาวน์อิสระของแอ็กชัน ไม่ใช่ GCD |

เปลี่ยนสีได้ทั้งหมด แอ็กชันหลายเป้าหมายอาจให้ผลต่างกัน ไอคอนจะรวมธงผลที่สังเกตได้จากการใช้ครั้งนั้น แสง critical direct hit ไม่ได้หมายความว่าทุกเป้าหมายได้รับผลเดียวกัน

Recuperate และ Shadowbringer มี **แถบคูลดาวน์อิสระสีน้ำเงินขนาดสั้น** ในเลน ability ด้วย แถบนี้ไม่ทำให้แอ็กชันกลายเป็น GCD

### ทำไมบางครั้งแถบสีม่วงหรือข้าวหลามตัดหายไป

แถบสีม่วงใช้การสังเกตแอนิเมชันของตัวเองจริง การสังเกตที่ขาดหาย การเชื่อมโยงไม่แน่นอน การหยุด หรือการถูกแอ็กชันอื่นแทนที่ อาจทำให้แถบหาย ขาด หรือสั้นลง เครื่องหมายแทนที่จะปรากฏเฉพาะเมื่อยืนยันว่าแอ็กชันอื่นเขียนทับแอนิเมชัน การจบตามปกติไม่เพิ่มข้าวหลามตัดสีส้ม

ข้าวหลามตัดสีชมพูต้องมาจากผลตอบกลับจริงเช่นกัน หากไม่มีผลตอบกลับ เชื่อมโยงไม่ได้อย่างน่าเชื่อถือ หรือเป็นช่วงที่ยังไม่รองรับ ปลั๊กอินจะไม่เดาเครื่องหมายจากคำอธิบาย

**การไม่มีแถบหรือเครื่องหมายไม่ใช่หลักฐานว่าแอ็กชันล้มเหลว** ปลั๊กอินไม่ใช้ความยาว GCD หรือ animation lock แทนเวลาเล่นแอนิเมชัน

## วิธีอ่านแถวสถานะ

แถวสถานะแสดง **สถานะที่มีอยู่บนตัวละครของคุณจริงเป็นหลัก** ไม่ว่าจะมาจากคุณ พันธมิตร หรือศัตรู การที่พันธมิตรใช้แอ็กชันเพียงอย่างเดียวไม่ถือเป็นหลักฐานว่าคุณได้รับผล

buff แสดงด้วยไอคอนเริ่ม/สิ้นสุดที่เชื่อมด้วยแถบ:

- ไอคอนเริ่มเคลื่อนไปตามเวลา และจะไม่ถูกทำซ้ำที่ขอบซ้ายก่อนจะไปถึงขอบ
- เมื่อถึงขอบจะเข้าสู่คิว หากทราบเวลาคงเหลือ จะแสดงตัวเลขไม่เกินสองหลักด้านล่าง โดยไม่มีหน่วยและไม่แสดงศูนย์
- สถานะที่จบก่อนจะอยู่ทางขวามากกว่าเพื่อมองเห็นได้ง่าย
- **ไอคอนที่มีขีดแดงเล็กด้านล่างคือจุดสิ้นสุด** หากทราบเวลาที่คาดว่าจะจบ ไอคอนอาจปรากฏในพื้นที่อนาคตก่อนหมด ขีดแดงไม่ได้หมายความว่าสถานะจบแล้ว
- หลังจบ จุดสิ้นสุดจะเคลื่อนไปอดีต และช่วงนั้นจะหายเมื่อไปพบไอคอนเริ่ม

สถานะจากแหล่งต่างกันสามารถบันทึกแยกกัน การรีเฟรช การซ้อน และการลบจะอิงการเปลี่ยนแปลงจริงในรายการสถานะ ไม่สร้างจำนวนชั้นจากจำนวนครั้งที่ใช้แอ็กชัน

ไม่ได้แสดงทุกสถานะ ปลั๊กอินคัดกรอง buff ของ job ที่ผ่านการตรวจสอบ และตัดตัวบ่งชี้การเลือก role action สถานะพร้อมใช้ หรือสถานะต่อเนื่องบางชนิด รายการนี้ยังไม่ใช่ฐานข้อมูลที่สมบูรณ์ หากต้องการเพิ่ม buff โปรดเปิด issue

**ปลั๊กอินแสดงเฉพาะสถานะและเวลานับถอยหลังที่ยืนยันได้** หากอ่านเวลาคงเหลือไม่ได้ จะไม่แสดงตัวเลข เงื่อนไขอย่าง “ต้องอยู่ในการต่อสู้” ยังไม่ได้รับการประเมินแยกต่างหาก

## การตั้งค่าที่ใช้บ่อย

| ตำแหน่ง | ตัวเลือก |
| --- | --- |
| ด้านบนการตั้งค่า | ภาษา สเกล หยุด/เล่นต่อ และล้างบันทึก |
| Display | เปิดใช้ ล็อกให้คลิกทะลุ แสดงเฉพาะต่อสู้ ซ่อนใน cutscene แถวสถานะ การสังเกตแอนิเมชันแบบ native ทิศทาง และพื้นหลัง |
| Layout | ขนาดไอคอน ความสูง/ระยะห่าง ตำแหน่งและความหนาแถบ GCD/ability ตำแหน่งการร่าย/แอนิเมชัน |
| Tracks | การมองเห็นและสีของแทร็กเวลา คูลดาวน์อิสระสั้น ability และ auto-attack |
| Time | พิกเซลต่อวินาที ช่วงประวัติ พื้นที่อนาคต เส้นตาราง และการแบ่งย่อย |
| Feedback | สีแสง critical/direct hit สีเครื่องหมายแทนที่ และความทึบของไอคอนเอฟเฟกต์ |

ป้อนค่าโดยตรงหรือวางเมาส์เหนือช่องตัวเลขแล้วหมุนล้อ สเกลโดยรวมรองรับ **0.2–2.0×** รวมข้อความบนไทม์ไลน์

UI รองรับภาษาจีนตัวย่อ/ตัวเต็ม อังกฤษ เยอรมัน ฝรั่งเศส และญี่ปุ่น ครั้งแรกจะตามภาษา UI ของ Dalamud และเลือกเองได้ ชื่อแอ็กชันและสถานะใช้แหล่งข้อมูลหลายภาษาที่มี และอาจย้อนกลับไปใช้ภาษาอังกฤษ ภาษาของไคลเอนต์ หรือ ID ชื่อผู้เล่นจะไม่ถูกแปล แก้ `ui-localization.txt` ข้าง DLL แล้วโหลดปลั๊กอินใหม่เพื่อแก้ข้อความ UI; ไฟล์นี้ไม่ควบคุมชื่อแอ็กชันหรือสถานะ

## คำถามที่พบบ่อย

### ไม่เห็นไทม์ไลน์ในเกม

ตรวจว่าคุณอยู่ในพื้นที่ PvP ที่รองรับ ปลั๊กอินเปิดอยู่ และตรวจ **Combat only** กับ **Hide in cutscene** หากยังไม่เห็น ให้ดูสถานะใน **Diagnostics** การอัปเดตเกมอาจต้องรอการแก้ความเข้ากันได้

### ทำไมกดแอ็กชันซ้ำแล้วไม่แสดงทุกครั้ง

ไทม์ไลน์แสดงการใช้แอ็กชันที่สังเกตได้ ไม่ใช่การคลิกทางกายภาพ การกดที่ไม่ก่อคำขอของเกมสังเกตไม่ได้ และการกดซ้ำที่ล้มเหลวจะไม่สร้างชุดไอคอน

### ทำไมความเสียหายที่เกิดอัตโนมัติใช้ไอคอนโปร่งแสง

ปลั๊กอินอาจได้รับเอฟเฟกต์ที่เกิดจากคุณแต่ไม่มีบันทึกการใช้ด้วยตนเอง การระเบิดอัตโนมัติสร้างความเสียหายจริงโดยไม่ต้องกดใหม่ ช่วงที่เชื่อมโยงได้อย่างน่าเชื่อถือจะอัปเดตแอ็กชันเดิม ส่วนเอฟเฟกต์จริงอื่นอาจคงเป็นไอคอนโปร่งแสง

### เวลาผลตอบกลับคือเวลาตัดสินการโจมตีของเซิร์ฟเวอร์หรือไม่

ไม่ใช่ เป็นเวลาที่ไคลเอนต์ของคุณได้รับข้อความและรวมความล่าช้าทั้งหมด การเล่นแอนิเมชันไม่ใช่ snapshot ของเซิร์ฟเวอร์ และการร่ายจบไม่ได้ระบุเวลาที่เร็วที่สุดซึ่งเคลื่อนไหวได้

### อัปโหลดข้อมูลหรือบันทึกการแข่งขันทั้งเกมหรือไม่

ไม่ทำโดยอัตโนมัติ เก็บเฉพาะข้อมูลล่าสุดที่มีขอบเขตในหน่วยความจำ และรีเซ็ตเมื่อเปลี่ยนพื้นที่หรือล้างบันทึก ข้อมูลวินิจฉัยจะถูกคัดลอกไปคลิปบอร์ดในเครื่องเฉพาะเมื่อกดปุ่ม และอาจมี entity ID, action/status ID และเวลา โปรดตรวจสอบก่อนแบ่งปัน

## ข้อจำกัดและข้อควรระวัง

- หน้าต่างเชื่อมโยงผลของแต่ละแอ็กชันยาวไม่เกิน **14 วินาที** ผลที่ช้าหรือกำกวมจะไม่ถูกบังคับเชื่อมโยง
- ประวัติจำกัด 256 รายการและ 120 วินาที รายการสถานะก็มีขีดจำกัด
- การสังเกตแอนิเมชันเน้นตัวละครของคุณ และไม่ได้สร้างแอนิเมชันฝั่งเป้าหมาย กระสุน หรือเอฟเฟกต์พื้นขึ้นใหม่ทั้งหมด
- การสังเกตแบบ native ใช้อินเทอร์เฟซภายในเกม การอัปเดตอาจทำให้เสียหรือไม่เสถียร การปิดไม่จำเป็นต้องนำ observation hook ทั้งหมดออก
- เป็นปลั๊กอินภายนอกที่ไม่เป็นทางการ ไม่มีการรับประกันความปลอดภัยของบัญชีหรือการทำงานโดยไม่ crash โปรดเข้าใจกฎของเกมและแพลตฟอร์ม

## การรายงานปัญหา

โปรดระบุรุ่นปลั๊กอิน ภูมิภาค/รุ่นเกม ภาษา job และชื่อแอ็กชัน การเกิดแบบ manual/automatic สิ่งที่คาดหวัง สิ่งที่เกิดจริง และขั้นตอนทำซ้ำ แนบภาพหรือ GIF สั้น ๆ ข้อมูลวินิจฉัยเอฟเฟกต์สำหรับปัญหาการเชื่อมโยง และ Dalamud log ที่ลบข้อมูลส่วนตัวสำหรับปัญหาการโหลด อย่าแบ่งปัน token รหัสผ่าน หรือบันทึกส่วนตัวที่ไม่เกี่ยวข้อง
