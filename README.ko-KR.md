FINAL FANTASY XIV PvP를 위한 개인용 실시간 기술 타임라인입니다.

기술 사용, 시전, 공용 재사용 대기시간(GCD), 애니메이션 잠금, 자신의 애니메이션, 효과 피드백을 하나의 타임라인에서 확인할 수 있습니다. 기술을 언제 사용했고 효과가 언제 도착했으며 그 사이에 어떤 능력을 끼워 넣었는지 검토할 수 있습니다.

![PvP Timeline 게임 내 미리보기](assets/pvp-timeline-preview.gif)

> 테스트 버전입니다. 게임 업데이트로 관측과 표시가 달라질 수 있으며 일부 기술 단계에는 피드백이 없을 수 있습니다. 타임라인은 로컬 관측을 보여 줄 뿐 서버 내부 판정을 정확히 재구성하지 않으며 기술을 자동으로 사용하지 않습니다.

## 작동 방식

![로컬 관측과 메시지 흐름](assets/how-pvp-timeline-works.png)

그림은 게임 클라이언트와 서버가 주고받는 메시지와 플러그인이 로컬에서 관측한 시간 정보를 구분합니다. PvP Timeline은 수락된 기술 요청, 로컬에서 보이는 시전·재사용 상태, 애니메이션 잠금, 자신의 애니메이션 재생, 수신한 효과 메시지, 현재 상태 스냅샷을 기록합니다. 색상 트랙은 기본 타임라인과 같은 뜻입니다.

플러그인은 추가 전투 패킷을 보내지 않고 서버 내부 판단을 볼 수 없습니다. 게임 기술 요청으로 이어지지 않은 물리적 입력은 관측할 수 없습니다. 효과 피드백 시간은 로컬 클라이언트가 메시지를 받은 시점이므로 네트워크·서버·클라이언트 처리 지연을 포함합니다.

## 주요 기능

- **기술 레인 분리:** 아래의 큰 아이콘은 마법, 무기 기술, 일부 특수 기술을, 위의 작은 아이콘은 능력을 최대 두 줄로 표시합니다.
- **시간 트랙 분리:** GCD, 시전 시간, 애니메이션 잠금, 애니메이션 재생을 따로 기록합니다.
- **효과 피드백:** 피해, 회복, 상태 부여 등은 분홍색 마름모로 표시하며 극대화·직격 결과는 원래 아이콘을 은은하게 빛냅니다.
- **지연 효과:** 지원되는 자동 폭발과 후속 단계는 원래 사용 기록에 연결하거나, 새 입력을 꾸며 내지 않고 실제 발동 효과를 반투명 아이콘으로 표시합니다.
- **자신의 상태:** 선별한 강화 효과와 관측된 약화 효과의 간결한 기록과 시간.
- **표시 사용자 지정:** 클릭 통과 잠금, 가로/세로 배치, 역방향 스크롤, 색상, 배경 투명도, 아이콘 크기, 전체 배율.
- **일시 정지와 검토:** 화면을 멈춰 최근 기술을 보거나 기록을 지울 수 있습니다.

관측은 지원되는 **늑대우리 부두, 크리스탈라인 컨플릭트, 전장, 경쟁의 날개** 지역으로 제한됩니다. 일반 PvE 지역에서는 작동하지 않으며 새 지도는 지원 목록 갱신이 필요합니다.

## 시작하기

### 설치

**Dalamud API 15** 플러그인을 실행할 수 있는 환경이 필요합니다. 현재 게임과 Dalamud에 맞는 버전을 사용하세요.

1. Dalamud가 활성화된 XIVLauncher를 설치하고 실행합니다.
2. **Dalamud Settings → Experimental**을 엽니다.
3. 다음 저장소 URL을 추가합니다.

   ```text
   https://raw.githubusercontent.com/chefiffer/dalamud-plugins/main/repo.json
   ```

4. 플러그인 설치 관리자에서 **PVPTimeline**을 검색하여 설치합니다.
5. 게임 채팅에서 설정 명령을 입력합니다.

   ```text
   /pvptimeline
   ```

6. 늑대우리 부두 또는 지원되는 PvP 지도에서 기술을 사용해 타임라인을 확인합니다.

### 첫 설정

처음에는 **Combat only**를 끄고 늑대우리 부두의 허수아비에서 시험하세요.

1. **Display**에서 오버레이 잠금을 풀고 이동·크기 조절을 합니다.
2. **Layout**에서 GCD/능력 아이콘 크기, 막대 위치와 두께를 조절합니다.
3. 배치가 끝나면 **Locked**를 켜 클릭이 통과되게 합니다.

잠긴 타임라인은 직접 클릭할 수 없습니다. `/pvptimeline`으로 설정을 다시 열며, 잠금 해제 중에는 우클릭으로도 열 수 있습니다.

## 타임라인 읽기

### 기술 아이콘과 시간

`0s`는 현재 관측 시각이고 음수는 과거입니다. 실시간 표시 중 격자와 시간은 고정되고 기술과 막대가 기록 방향으로 이동합니다.

큰 아이콘이 있는 아래 레인이 모두 GCD 기술이라는 뜻은 아닙니다. 일부 리미트 브레이크와 특수 기술도 이곳에 나타납니다. 공유 재사용 대기시간을 실제로 관측했을 때만 파란 GCD 막대를 그립니다.

| 기본 표시 | 의미 |
| --- | --- |
| 파란 막대 | 관측된 공용 재사용 대기시간(GCD) |
| 초록 막대 | 로컬에서 관측한 시전 구간 |
| 짧은 밝은 노란 막대 | GCD와 별도로 기록한 애니메이션 잠금 |
| 보라 막대 | 자신의 애니메이션 재생 관측 구간 |
| 채운 분홍 마름모 | 피해, 회복, 상태 부여 등의 직접 피드백; 검증된 일부 이동 기술은 서버 응답일 수 있음 |
| 빈 분홍 마름모 | 시각 효과나 게이지 변화 등의 피드백; 이것만으로 피해나 회복을 입증하지 않음 |
| 반투명 기술 아이콘 | 미확인 시전 또는 수동 사용 기록이 없는 실제 발동 효과; 다시 눌렀다는 뜻이 아님 |
| 아이콘 광택 | 실제 효과 메시지의 극대화, 직격, 극대 직격 플래그 |
| 얇은 회색 막대(기본 꺼짐) | GCD가 아닌 기술 자체 재사용 대기시간 |

색상은 모두 바꿀 수 있습니다. 다중 대상 기술의 결과는 대상마다 다를 수 있으며 아이콘은 해당 사용에서 관측된 플래그를 합칩니다. 극대 직격 광택이 모든 대상을 그렇게 적중했다는 뜻은 아닙니다.

회복과 섀도브링어에는 능력 레인에 **짧고 독립된 파란 재사용 막대**도 있습니다. 독립 재사용 기술이며 GCD 기술이 되는 것은 아닙니다.

### 보라 막대나 마름모가 없는 이유

보라 막대는 자신의 애니메이션을 실제로 관측했을 때만 표시됩니다. 관측 누락, 불확실한 연결, 일시 정지, 다른 기술의 덮어쓰기로 빠지거나 끊기거나 짧아질 수 있습니다. 다른 기술이 애니메이션을 덮어썼다고 확인될 때만 교체 표식을 표시하며 정상 종료에는 주황 마름모를 추가하지 않습니다.

분홍 마름모도 실제 효과 피드백이 필요합니다. 피드백이 없거나 안정적으로 연결할 수 없거나 미지원 단계이면 설명만 보고 추측하지 않습니다.

**막대나 표식이 없다고 기술 실패가 입증되는 것은 아닙니다.** GCD나 애니메이션 잠금 시간을 애니메이션 재생 시간으로 대신하지 않습니다.

## 상태 행 읽기

상태 행은 주로 **자신에게 실제로 존재하는 상태**를 보여 줍니다. 자신·아군·적이 부여한 상태일 수 있습니다. 아군이 기술을 썼다는 사실만으로 자신이 효과를 받았다고 추정하지 않습니다.

강화 효과는 시작/종료 아이콘과 연결 막대로 표시합니다.

- 시작 아이콘은 시간에 따라 이동하며 왼쪽 끝에 닿기 전에 복제하지 않습니다.
- 끝에 도달하면 대기열로 들어가고 남은 시간을 알면 단위와 0 없이 최대 두 자리 숫자를 표시합니다.
- 종료가 빠른 상태일수록 대기열 오른쪽에 둡니다.
- **작은 빨간 밑줄이 있는 아이콘은 종료점입니다.** 예상 종료 시간을 알면 종료 전 미래 영역에 나타날 수 있으며 밑줄은 이미 끝났다는 뜻이 아닙니다.
- 종료 후 종료점은 과거로 이동하고 시작점과 만나면 구간이 사라집니다.

서로 다른 출처는 따로 기록할 수 있습니다. 갱신, 중첩, 해제는 실제 상태 목록 변화에 따르며 기술 사용 횟수로 중첩을 꾸며 내지 않습니다.

모든 상태를 표시하지는 않습니다. 검토된 직업 강화 효과를 선별하고 일부 역할 기술 선택, 사용 준비, 후속 상태를 제외합니다. 아직 완전한 데이터베이스가 아니므로 추가를 원하면 Issue를 열어 주세요.

**확인 가능한 상태와 남은 시간만 표시합니다.** 읽을 수 있는 남은 시간이 없으면 숫자를 표시하지 않으며 ‘전투 중’ 같은 조건은 아직 별도로 판단하지 않습니다.

## 주요 설정

| 위치 | 옵션 |
| --- | --- |
| 설정 상단 | 언어, 전체 배율, 일시 정지/재개, 기록 지우기 |
| Display | 활성화, 클릭 통과, 전투 중만, 컷신 숨김, 상태 행, 네이티브 애니메이션 관측, 방향, 배경 |
| Layout | 아이콘 크기, 능력 높이/간격, GCD/능력 막대 위치와 두께, 시전/애니메이션 위치 |
| Tracks | 시간 트랙, 짧은 독립 재사용, 능력, 자동 공격의 표시와 색상 |
| Time | 초당 픽셀, 기록 범위, 미래 공간, 격자, 초당 분할 |
| Feedback | 극대/직격 광택, 애니메이션 교체 표식, 발동 효과 투명도 |

값을 직접 입력하거나 숫자 칸 위에서 휠로 조절할 수 있습니다. 전체 배율은 텍스트를 포함해 **0.2–2.0배**입니다.

UI는 중국어 간체/번체, 영어, 독일어, 프랑스어, 일본어를 지원합니다. 처음에는 Dalamud UI 언어를 따르며 직접 선택할 수 있습니다. 기술과 상태 이름은 가능한 다국어 자원을 사용하고 누락 시 영어, 클라이언트 언어 또는 ID로 대체될 수 있습니다. 플레이어 이름은 번역하지 않습니다. DLL 옆의 `ui-localization.txt`는 UI 문구만 제어하며 수정 후 플러그인을 다시 불러오세요.

## 자주 묻는 질문

### 타임라인이 보이지 않습니다

지원되는 PvP 지역인지, 플러그인이 켜졌는지, **Combat only**와 **Hide in cutscene** 설정을 확인하세요. **Diagnostics**에서 관측 상태도 확인할 수 있습니다. 게임 업데이트 후 호환 수정이 필요할 수 있습니다.

### 연속 입력이 모두 나타나지 않는 이유는 무엇인가요?

물리적 클릭이 아니라 관측 가능한 기술 사용을 표시합니다. 게임 요청이 되지 않은 입력은 관측할 수 없으며 실패한 연속 입력으로 아이콘을 채우지 않습니다.

### 자동 발동 피해가 반투명인 이유는 무엇인가요?

자신이 만든 효과라도 대응하는 수동 사용 기록이 없을 수 있습니다. 자동 폭발은 새 입력 없이 실제 피해를 줍니다. 안정적으로 연결한 단계는 원래 기술에 반영하고 다른 실제 발동 효과는 반투명으로 남을 수 있습니다.

### 피드백 시간은 서버 판정 시간인가요?

아닙니다. 로컬 클라이언트가 받은 시각이며 모든 처리 지연을 포함합니다. 애니메이션 재생도 서버 적중 시점이 아니고 시전 종료도 가장 빠른 이동 가능 시각을 확정하지 않습니다.

### 데이터를 업로드하거나 경기 전체를 저장하나요?

자동으로 하지 않습니다. 제한된 최근 기록만 메모리에 보관하며 지역 이동이나 지우기로 초기화됩니다. 진단 정보는 복사 버튼을 눌렀을 때만 로컬 클립보드에 기록되고 ID와 시간 정보가 포함될 수 있으니 공유 전 확인하세요.

## 제한과 주의사항

- 기술별 효과 연결 창은 최대 **14초**이며 늦거나 모호한 피드백을 강제로 연결하지 않습니다.
- 기술 기록은 256개, 120초로 제한되고 상태 기록에도 상한이 있습니다.
- 애니메이션 관측은 자신의 캐릭터 중심이며 대상 애니메이션, 투사체, 지면 효과를 완전히 재구성하지 않습니다.
- 네이티브 관측은 게임 내부 인터페이스를 사용하므로 업데이트로 고장 나거나 불안정할 수 있습니다. 꺼도 모든 관측 후크가 제거되는 것은 아닙니다.
- 비공식 제3자 플러그인입니다. 게임과 플랫폼 규칙을 확인하세요. 계정 안전이나 무충돌 동작을 보장하지 않습니다.

## 문제 신고

플러그인 버전, 게임 지역/버전, 언어, 직업과 기술, 수동/자동 발동 여부, 기대/실제 동작, 재현 절차를 알려 주세요. 가능하면 스크린샷이나 짧은 GIF, 연결 문제의 효과 진단, 로딩 문제의 개인정보 제거 Dalamud 로그를 첨부하세요. 토큰, 비밀번호, 무관한 개인 로그는 공유하지 마세요.

## 감사의 말

타임라인 표시, 잠금 상호작용, 사용자 지정 방식은 다음 프로젝트를 참고했습니다.

- [ActionTimelineEx](https://github.com/Ted-Jin-Lab/ActionTimelineEx)
- [ActionTimelineReplacement](https://github.com/Loskh/ActionTimelineReplacement)

PvP Timeline은 해당 프로젝트의 공식 버전이 아닙니다. 게임 아이콘과 관련 자료의 권리는 각 권리자에게 있습니다.
