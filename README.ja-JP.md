# PvP Timeline

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [한국어](README.ko-KR.md) | [Русский](README.ru-RU.md) | [Português (Brasil)](README.pt-BR.md) | [Español](README.es-ES.md) | [ไทย](README.th-TH.md) | [Tiếng Việt](README.vi-VN.md) | **日本語** | [Deutsch](README.de-DE.md) | [Français](README.fr-FR.md)

『ファイナルファンタジーXIV』の PvP 向け、個人用リアルタイム・アクションタイムラインです。

アクション使用、詠唱、GCD、アニメーションロック、自身のアニメーション、効果フィードバックを 1 本の時間軸で確認できます。いつアクションを使い、いつ効果を受け取り、その間にどのアビリティを挟んだかを振り返れます。

![PvP Timeline ゲーム内プレビュー](assets/pvp-timeline-preview.gif)

> これはテスト版です。ゲーム更新により観測や表示が影響を受ける場合があり、一部アクション段階のフィードバックはまだ欠ける可能性があります。タイムラインはローカル観測を表示するもので、サーバー内部の命中判定を正確に再構成するものではありません。アクションの自動化も行いません。

## 仕組み

![PvP Timeline のローカル観測とメッセージフロー](assets/how-pvp-timeline-works.png)

図は、ゲームクライアントとサーバー間のメッセージと、プラグインがローカルで観測する時間情報を分けて示しています。PvP Timeline は、受理されたアクション要求、ローカルで見える詠唱・リキャスト状態、アニメーションロック、自身のアニメーション再生、受信した効果メッセージ、現在のステータススナップショットを記録します。色付きトラックは標準タイムラインと同じ意味です。

プラグインが追加の戦闘パケットを送信することはなく、サーバー内部の判断処理も参照できません。ゲームのアクション要求にならなかった物理的なボタン入力は観測できません。効果フィードバックの時刻はローカルクライアントがメッセージを受信した時刻であり、通信、サーバー、クライアントの処理遅延を含みます。

## 主な機能

- **アクションレーンの分離：** 下段の大きなアイコンは魔法、ウェポンスキル、一部の特殊アクションを表示します。上段の小さなアイコンはアビリティを最大 2 行で表示し、オーバーレイをコンパクトに保ちます。
- **時間トラックの分離：** GCD、詠唱時間、アニメーションロック、アニメーション再生を別々に記録します。
- **効果フィードバック：** 受信したダメージ、回復、ステータス付与などをピンクの菱形で示します。クリティカル／ダイレクトヒットは元のアクションアイコンを淡く発光させます。
- **遅延効果：** 対応する自動爆発や後続段階を元の使用に関連付け、別の手動入力を作り出さず、実際に発動した効果を半透明アイコンで表示できます。
- **自身のステータス：** 選別したバフと観測したデバフを含む、コンパクトなステータス履歴と時間表示。
- **外観設定：** クリック透過ロック、横／縦配置、逆スクロール、色、背景透過度、アイコンサイズ、全体スケール。
- **停止して確認：** 表示を一時停止して直近のアクションを確認したり、記録を消去して再テストしたりできます。

観測は、対応済みの **ウルヴズジェイル係船場、クリスタルコンフリクト、フロントライン、ライバルウィングズ** のエリアに限定されます。通常の PvE エリアでは有効になりません。新しいマップには対応リストの更新が必要です。

## はじめに

### インストール

**Dalamud API 15** プラグインを実行できる環境が必要です。現在のゲームと Dalamud のバージョンに対応するリリースを使用してください。

1. XIVLauncher をインストールして起動し、Dalamud が有効であることを確認します。
2. **Dalamud Settings → Experimental** を開きます。
3. 次のカスタムプラグインリポジトリ URL を追加します。

   ```text
   https://raw.githubusercontent.com/chefiffer/dalamud-plugins/main/repo.json
   ```

4. プラグインインストーラーで **PVPTimeline** を検索してインストールします。
5. ゲーム内チャットで次のコマンドを実行して設定を開きます。

   ```text
   /pvptimeline
   ```

6. ウルヴズジェイル係船場または対応 PvP マップでアクションを使い、タイムラインを確認します。

### 初回設定

まず **Combat only** をオフにし、ウルヴズジェイル係船場の木人で試してください。

1. **Display** タブでオーバーレイのロックを解除し、移動・サイズ変更します。
2. **Layout** タブで GCD／アビリティのアイコンサイズ、バー位置、太さを調整します。
3. 配置が決まったら **Locked** を有効にしてクリック透過にし、誤操作を防ぎます。

ロック中のタイムラインは直接クリックできません。`/pvptimeline` で設定を開き直してください。ロック解除中はタイムラインを右クリックして設定を開くこともできます。

## タイムラインの読み方

### アクションアイコンと時間

`0s` は現在の観測時刻、負の値は過去です。ライブ表示中はグリッドと時間表示が固定され、アクションとバーが履歴側へ移動します。

大きなアイコンの下段は「すべて GCD アクション」という意味ではありません。一部のリミットブレイクや特殊アクションもここに表示されます。共有リキャストを実際に観測した場合だけ、青い GCD バーを描画します。

| 標準表示 | 意味 |
| --- | --- |
| 青いバー | 観測された GCD |
| 緑のバー | ローカルで観測された詠唱区間 |
| 短い明黄色バー | GCD と別に記録されたアニメーションロック |
| 紫のバー | 自身のアニメーション再生を観測した区間 |
| ピンクの塗りつぶし菱形 | ダメージ、回復、ステータス付与などの直接フィードバック。検証済みの一部移動アクションではサーバー応答を示す場合もあります |
| ピンクの中空菱形 | 視覚効果やゲージ変化などのフィードバック。これだけではダメージや回復の発生を証明しません |
| 半透明アクションアイコン | 未確認の詠唱、または対応する手動使用記録がない実発動効果。もう一度ボタンを押したという意味ではありません |
| アイコンの発光 | 実際の効果メッセージに含まれるクリティカル、ダイレクトヒット、クリティカルダイレクトヒット。色は変更可能です |
| 細い灰色バー（初期設定では非表示） | GCD ではなく、アクション固有のリキャスト |

すべての色を変更できます。複数対象アクションでは対象ごとに結果が異なる場合があり、アイコンはその使用で観測した命中フラグを統合します。クリティカルダイレクトヒットの発光は、全対象で発生したという意味ではありません。

快気とシャドウブリンガーは、アビリティレーンに**短い独立した青色リキャストバー**も表示します。独立リキャストのままであり、青いバーによって GCD アクションになるわけではありません。

### 紫のバーや菱形がないことがあるのはなぜですか？

紫のバーは自身のアニメーションを実際に観測した場合だけ表示します。観測漏れ、関連付けの不確実性、一時停止、別アクションによる置き換えにより、欠落・中断・短縮する場合があります。置換マーカーは別アクションがアニメーションを上書きしたと確認できた場合だけ表示し、通常終了ではオレンジの菱形を追加しません。

ピンクの菱形にも実際の効果フィードバックが必要です。フィードバックがない、確実に関連付けられない、未対応段階に属する場合、説明文から推測して表示しません。

**バーやマーカーがないことは、アクションが失敗した証拠ではありません。** GCD やアニメーションロックの長さをアニメーション再生時間の代わりに使うこともありません。

## ステータス行の読み方

ステータス行は主に、**実際に自分のキャラクターに付与されているステータス**を表示します。自分、味方、敵のいずれが付与したものでも構いません。味方がアクションを使ったことだけを根拠に、自分が効果を受けたとは扱いません。

バフは開始／終了アイコンと接続バーでコンパクトに表示します。

- ステータス出現後、開始アイコンは時間とともに移動し、元のアイコンが左端に達する前に重複表示しません。
- 開始アイコンが端に達すると待機アイコン列に入ります。残り時間が分かる場合、単位やゼロを付けず、最大 2 桁のカウントダウンを下に表示します。
- 待機アイコンは終了時刻順で、早く終了するものほど右に配置します。
- **小さな赤い下線付きアイコンは終了点です。** 予想終了時刻が分かる場合、終了前に未来領域へ表示されることがあります。下線は既に終了したという意味ではありません。
- 終了後、終了点は過去へ移動し、開始アイコンと重なるとその区間が消えます。

異なる付与元のステータスは別々に記録できます。更新、スタック、解除は実際のステータス一覧の変化に従い、アクション使用回数からスタックを作りません。

すべてのステータスを表示するわけではありません。確認済みのジョブバフを選別し、一部のロールアクション選択表示やアクション準備／派生状態を除外します。選別は調整中で、全ジョブの完全なステータスデータベースではありません。追加表示を希望するバフがあれば Issue または開発者へ連絡してください。

**確認できるステータスとカウントダウンだけを表示します。** 読み取れる残り時間がなければカウントダウンは表示しません。効果の一部に「戦闘中であること」などが必要かどうかは、現在個別に評価していません。

## 主な設定

| 場所 | 設定内容 |
| --- | --- |
| 設定上部 | 言語、全体スケール、ライブ表示の停止／再開、記録消去 |
| Display | 有効化、クリック透過ロック、戦闘中のみ、カットシーン時非表示、ステータス行、ネイティブアニメーション観測、向き、背景 |
| Layout | 2 種類のアイコンサイズ、アビリティ領域の高さと行間、GCD／アビリティバーの位置と太さ、詠唱／アニメーション位置 |
| Tracks | 時間トラック、短い独立リキャスト、アビリティ、オートアタックの表示と色 |
| Time | 1 秒あたりのピクセル、履歴範囲、未来領域、グリッド、1 秒あたりの分割数 |
| Feedback | クリティカル／ダイレクトヒット発光色、アニメーション置換マーカー色、発動効果アイコン透過度 |

数値を直接入力するか、数値欄にマウスを置いてホイールで増減できます。ホイール調整時はその欄の文字編集を終了します。全体スケールはタイムライン文字を含め **0.2～2.0 倍**に対応します。

インターフェースは簡体字中国語、繁体字中国語、英語、ドイツ語、フランス語、日本語に対応しています。初回は Dalamud の UI 言語に従い、手動選択もできます。アクション名とステータス名は利用可能な多言語リソースを使い、新規アクションや欠落翻訳は英語、クライアント言語、ID にフォールバックする場合があります。プレイヤー名は翻訳しません。翻訳上の問題は Issue または開発者へ報告してください。

UI 翻訳を修正するには DLL と同じ場所の `ui-localization.txt` を編集し、プラグインを再読み込みします。このファイルは UI 文字列だけを制御し、アクション名やステータス名は対象外です。

## FAQ

### ゲーム内にタイムラインが表示されません

対応 PvP エリアにいて、プラグインが有効か確認してください。**Combat only** と **Hide in cutscene** も確認します。それでも表示されない場合は、設定タブ下の **Diagnostics** で観測状態を確認してください。ゲーム更新後は互換性修正が必要な場合があります。

### アクションを連打しても、すべての入力が表示されないのはなぜですか？

タイムラインは物理的なマウスクリックではなく、観測可能なアクション使用を表示します。ゲームのアクション要求にならなかった入力は観測できず、失敗した連打で赤いバーやアイコンを埋めません。

### 自動発動ダメージが半透明アイコンなのはなぜですか？

自分が原因の効果を受信しても、対応する手動アクション使用記録がない場合があります。自動爆発はその時点の追加ボタン入力なしに実ダメージを与えます。確実に関連付けられる段階は元アクションへ反映し、それ以外の実発動効果は半透明アイコンとして残る場合があります。

### フィードバック時刻はサーバーの命中判定時刻ですか？

いいえ。ローカルクライアントがメッセージを受信した時刻で、通信、サーバー、クライアント処理の影響を含みます。アニメーション再生の観測もサーバーの命中スナップショットではありません。詠唱終了も、移動可能になった最速時刻を確定しません。

### データをアップロードしたり、試合全体を保存したりしますか？

タイムラインは戦闘データを自動アップロードせず、試合全体のログを継続保存しません。上限付きの直近記録をメモリに保持し、エリア移動や記録消去でリセットします。

診断情報はコピーボタンを押した場合だけローカルクリップボードへ書き込みます。エンティティ ID、アクション／ステータス ID、時間情報を含む場合があるため、共有前に確認してください。

## 制限と注意事項

- 各アクション使用のフィードバック関連付け時間は最大 **14 秒**です。期限切れのフィードバックを永久に保留せず、発生元シーケンスがない、または候補が複数ある場合は強制的に割り当てません。
- アクション履歴は 256 件、120 秒までです。表示履歴範囲は別に設定します。現在／過去のステータスにも件数上限があります。
- アニメーション観測は現在、自身のキャラクターが中心です。対象側のアニメーション、飛翔物、地面効果を完全には再構成しません。
- ネイティブアニメーション観測はゲーム内部インターフェースを使用します。ゲーム更新で動作不能や不安定になる可能性があります。設定で無効化できますが、プラグインのすべての観測フックを削除するわけではありません。
- 非公式の第三者プラグインです。使用前にゲームとプラグインプラットフォームの規則を理解してください。アカウント安全性や無クラッシュ動作を保証しません。

## 問題を報告する

次の情報を添えてください。

1. プラグインバージョン、ゲーム地域／バージョン、選択言語。
2. ジョブとアクション名、手動／自動発動の別。
3. 期待した動作、実際の動作、再現手順。
4. スクリーンショットまたは短い GIF。関連付け問題は設定からコピーした効果診断、読み込み失敗は個人情報を除いた Dalamud ログも可能なら添付してください。

スクリーンショットは表示問題、診断情報は観測漏れと関連付け／描画問題の区別に役立ちます。アカウントトークン、パスワード、無関係な個人ログを共有しないでください。
