# PvP Timeline

[English](README.md) | [简体中文](README.zh-CN.md) | **繁體中文** | [한국어](README.ko-KR.md) | [Русский](README.ru-RU.md) | [Português (Brasil)](README.pt-BR.md) | [Español](README.es-ES.md) | [ไทย](README.th-TH.md) | [Tiếng Việt](README.vi-VN.md) | [日本語](README.ja-JP.md) | [Deutsch](README.de-DE.md) | [Français](README.fr-FR.md)

為《最終幻想 XIV》PvP 設計的個人實時技能時間軸。

把「使用技能」「讀條」「GCD」「動畫鎖」「自身技能動畫」和「效果判定」放在同一條時間線上，幫助你回看剛才的操作：技能什麼時候交出去了，什麼時候判定，中間又插入了哪些能力技。

![PvP Timeline 遊戲內預覽](assets/pvp-timeline-preview.gif)

> 當前為測試版本。遊戲更新可能影響採集與顯示；部分技能的特殊階段仍可能缺少反饋。時間軸是本機觀測工具，不是伺服器內部判定的精確還原，也不提供自動施法功能。

## 工作原理

![PvP Timeline 本機觀測與訊息流](assets/how-pvp-timeline-works.png)

上圖把遊戲客戶端與伺服器之間交換的訊息，和外掛在本機觀察到的計時資訊區分開來。PvP Timeline 記錄已經形成的動作請求、本機可見的讀條與冷卻狀態、動作鎖、自身動畫播放、收到的效果訊息，以及本人當前的狀態快照。圖中的顏色與時間軸預設顯示的含義一致。

外掛不會額外傳送戰鬥資料包，也無法檢視伺服器內部的判定過程。沒有形成遊戲動作請求的物理按鍵無法被外掛觀察到。效果反饋時間表示本機客戶端收到訊息的時刻，因此其中包含網路傳輸、伺服器處理和客戶端處理延遲。

## 它能做什麼？

- **上下分層看技能**：下方使用較大的圖示顯示魔法、戰技及部分特殊動作，上方使用較小的圖示顯示能力技；能力技最多使用兩排，避免無限增高。
- **區分不同的時間**：公共冷卻、讀條、動作鎖和動畫各有獨立軌道，不把它們當作同一個東西。
- **觀察效果反饋**：傷害、治療、狀態應用等訊息到達後，在對應技能上標出粉色菱形；暴擊、直擊結果反饋到原技能圖示的柔光高亮上。
- **保留延遲觸發效果**：可識別的自動爆炸、後續階段等會關聯原釋放，或以半透明圖示顯示實際觸發效果，不偽造一次手動按鍵。
- **檢視自身 Buff**：在技能軸下方顯示緊湊的狀態歷史與計時，包含篩選後的增益及已觀測到的弱化狀態。
- **按習慣調整外觀**：支援鎖定穿透、橫向／縱向、反向滾動、顏色、背景透明度、圖示大小及整體縮放。
- **隨時凍結回看**：暫停畫面觀察剛才的技能順序，或清空當前記錄重新測試。

本外掛只在已支援的**狼獄停船場、水晶衝突、紛爭前線和烈羽爭鋒**區域啟用觀測，普通 PvE 區域不啟用。新增地圖需要更新支援列表。

## 安裝與開始使用

### 安裝

需要能夠執行 **Dalamud（衛月）API 15** 外掛的遊戲環境。請使用與當前遊戲和衛月版本相容的釋出包。

目前使用開發外掛方式載入：

1. 安裝並啟動 XIVLauncher，確認 Dalamud 已啟用。

2. 開啟 **Dalamud 設定 → 測試版**。

3. 新增下面的自定義外掛倉庫地址：

   ```text
   https://raw.githubusercontent.com/chefiffer/dalamud-plugins/main/repo.json
   ```

4. 開啟外掛安裝器，搜尋 **PVPTimeline** 並安裝。

5. 在遊戲聊天欄輸入以下命令開啟設定：

   ```text
   /pvptimeline
   ```

6. 進入狼獄停船場或受支援的 PvP 地圖，使用技能即可觀察時間軸。

### 第一次調整

建議先保持「僅戰鬥中」關閉，在狼獄停船場對木人測試：

1. 在設定的「顯示」頁解除鎖定，拖動時間軸到合適位置，並調整視窗大小。
2. 在「排版」頁調整 GCD 和能力技的圖示大小、條形位置與粗細。
4. 調好後啟用「鎖定」，讓滑鼠穿透時間軸，減少誤操作。

鎖定後無法直接點選時間軸，請透過 `/pvptimeline` 重新開啟設定。解鎖時也可以右鍵時間軸開啟設定。

## 怎樣看懂時間軸？

### 技能圖示與時間

`0s` 表示當前觀察時刻；負數表示已經過去的時間。正常執行時，刻度和數字保持固定，技能與時間條向歷史方向移動。

大號圖示所在的下軌不等於「所有技能都佔用公共冷卻」：部分極限技或特殊動作也會放在這裡。是否存在藍色公共冷卻條，以實際觀測到的共享冷卻為準。

| 預設顯示 | 含義 |
| --- | --- |
| 藍條 | 實際觀測到的公共冷卻（GCD） |
| 綠條 | 本機觀測到的讀條階段 |
| 明黃色短條 | 動作鎖，與公共冷卻分別記錄 |
| 紫條 | 已觀測到的自身動畫播放區間 |
| 粉色實心菱形 | 收到傷害、治療、狀態應用等直接效果反饋；部分已核對的位移技能也可表示服務端確認 |
| 粉色空心菱形 | 收到特效、量譜等反饋，不能據此認定造成了傷害或治療 |
| 半透明技能圖示 | 可能是尚未確認的讀條，或沒有對應手動釋放記錄的實際觸發效果；不等於又按了一次技能 |
| 圖示柔光 | 從實際效果訊息中讀取的暴擊、直擊或直暴結果；顏色可調整 |
| 灰色細條（預設關閉） | 技能自身的獨立冷卻，不是公共冷卻 |

以上顏色均可修改。同一個技能的多目標結果可能不同，圖示高亮會合並本次已觀測到的結果，並不表示所有目標都發生了直暴。

自愈和暗影鋒還有單獨的**自身短冷卻藍條**，顯示在能力技軌道。它們仍是獨立冷卻，不會因此變成 GCD 技能。

### 為什麼有時沒有紫條或菱形？

紫條只使用自身動畫的實際觀測。沒有采到、無法唯一關聯、動畫暫停或被其他技能覆蓋，都可能使它缺失、出現間斷或提前停止。只有確認被另一技能覆蓋時，才標記相應的中斷符號；普通結束不額外畫橙色菱形。

粉色菱形則來自實際效果反饋。沒有收到、無法可靠關聯，或效果屬於尚未支援的特殊階段時，不會按技能說明猜一個標記。

**沒有線或標記，不足以證明技能沒有生效。** 外掛也不會拿 GCD 或動作鎖的長度補成動畫時間。

## 怎樣看 Buff 行？

Buff 行主要展示**本人實際持有的狀態**。來源可以是自己、隊友或敵人，但不會僅憑隊友釋放了某個技能，就推斷自己一定獲得了對應效果。

增益採用緊湊的起止圖示與連線條：

- 狀態出現後，起始圖示隨時間移動；尚未到達左側邊界時，不會提前在邊界複製一個圖示。
- 起始圖示到達邊界後進入排隊區。已知剩餘時間時，在圖示下面顯示最多兩位數字，不帶單位、不顯示零。
- 排隊區按結束時間排列，較早結束的狀態靠右，便於先看到即將結束的狀態。
- **帶紅色小槓的圖示表示結束節點**。如果已知預計結束時間，它可以提前出現在未來區域；紅槓不表示該狀態此刻已經結束。
- 狀態結束後，結束節點繼續向歷史方向移動，與起始圖示相遇時，這一段顯示消失。

不同來源的狀態可分別記錄；重新整理、疊加或移除以本人狀態列表的實際變化為準，不按施法次數憑空增加層數。

不是所有狀態都會顯示。外掛會篩選已核對的職業增益，排除部分職能選擇標識、技能預備／續鍵狀態等。該篩選仍在完善中，不能將它當作完整的全職業 Buff 資料庫。如果您有想要新增顯示的 buff 請提交issue或者反饋給開發者。

**外掛只顯示能確認的狀態和倒數。**若你身上的增益沒有可讀取的剩餘時間，就不顯示倒數；需要進入戰鬥等條件才能生效的部分，目前不會單獨判斷。

## 常用設定

| 位置 | 可以調整什麼 |
| --- | --- |
| 設定頂部 | 語言、整體縮放，以及凍結／恢復實時、清空記錄 |
| 顯示 | 啟用、鎖定穿透、僅戰鬥中、過場隱藏、Buff 行、原生動畫觀測、方向和背景 |
| 排版 | 兩類圖示大小、能力技高度與排間距、GCD／能力技各自的條形位置和粗細、讀條及動畫位置 |
| 軌道 | 各類時間條的顯示與顏色、自身短冷卻、能力技和自動攻擊 |
| 時間 | 每秒畫素、歷史顯示範圍、未來預留、網格與每秒細分 |
| 高亮 | 暴擊／直擊柔光顏色、動畫覆蓋標記顏色、觸發效果圖示透明度 |

數值可以直接輸入，也可以將滑鼠停在對應輸入框上，用滾輪上調或下調；滾輪調整會結束該輸入框當前的文字編輯。整體縮放支援 **0.2–2.0 倍**，時間軸文字也隨之縮放。

支援簡體中文、繁體中文、英語、德語、法語和日語。首次使用預設跟隨衛月介面語言，也可手動選擇。技能與狀態名稱優先使用已有多語言名稱資源；新技能或缺失譯名可能回退到英文、客戶端名稱或編號。玩家姓名不會被翻譯。如果有語言翻譯問題請您提交issue或者反饋給開發者。

需要修訂介面翻譯時，可編輯 DLL 同目錄的 `ui-localization.txt` 後重新載入外掛。該檔案控制介面文字，技能和狀態名稱不在這個 TXT 中。

## 常見問題

### 進入遊戲後看不到時間軸

先確認當前位於受支援的 PvP 區域，外掛已啟用，並檢查是否開啟了「僅戰鬥中」或「過場隱藏」。仍不顯示時，開啟設定下方的「診斷」檢查觀測狀態；遊戲更新後可能需要等待相容性修復。

### 連續點選一個技能，為什麼沒有每次點選的圖示？

時間軸展示的是可觀測到的釋放過程，不是滑鼠點選記錄器。未產生遊戲動作請求的物理點選無法讀取；失敗連點也不會鋪成一串紅條或圖示。

### 自動觸發的傷害為什麼是半透明圖示？

外掛收到了由自己造成的效果，但未必存在對應的手動釋放記錄。例如自動爆炸會實際造成傷害，卻不代表你在那個時間又按了一次按鈕。能夠可靠關聯的階段會回填原技能，其他實際觸發效果可保留為半透明圖示。

### 反饋時間能當作技能的伺服器判定時間嗎？

不能。它是本機收到訊息的時刻，包含網路、伺服器與客戶端處理的影響；動畫觀測也不等於伺服器命中快照。讀條結束不等於已經測出了最早可移動的時刻。

### 它會上傳資料或儲存完整比賽嗎？

當前時間軸不自動上傳戰鬥資料，也不持續儲存完整比賽日誌。它保留有上限的近期記憶體記錄；換地圖或清空會重置記錄。

診斷資訊只有在點選複製按鈕後才寫入本機剪貼簿，可能包含實體 ID、技能／狀態 ID 和時間等資訊。分享前請自行檢查。

## 限制與使用提醒

- 每次釋放的反饋關聯視窗最長為 **14 秒**。超過截止時間的反饋不會無限佔用待確認位置；缺少來源序列或存在多個候選時，也不會強行配對。
- 動作歷史最多保留 256 條、最長 120 秒；介面可顯示的歷史範圍另有設定。當前狀態與歷史狀態也有數量上限，避免無限增長。
- 當前動畫觀測主要針對自身，不包含完整的目標側動畫、彈道或地面特效還原。
- 原生動畫觀測涉及遊戲內部介面。遊戲更新可能導致失效或穩定性問題；可在設定中關閉該觀測，但不應將此理解為解除安裝了外掛所有觀測介面。
- 這是非官方第三方外掛。請自行了解遊戲及外掛平臺的使用規則；本專案不作賬號安全或零崩潰保證。

## 反饋問題

提交問題時，建議提供：

1. 外掛版本、遊戲區域／版本、使用語言。
2. 職業、技能名稱，以及手動觸發還是自動觸發。
3. 期望顯示什麼、實際顯示什麼，以及可復現的操作順序。
4. 截圖或短 GIF；關聯錯誤時可附設定中複製的效果診斷，載入異常時可附脫敏後的衛月日誌。

截圖能說明顯示問題，診斷資料能幫助區分「沒有采到」和「採到了但關聯或繪製有誤」。請勿上傳賬號令牌、密碼或無關的私人日誌。
